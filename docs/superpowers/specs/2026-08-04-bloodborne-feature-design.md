# Bloodborne Feature Design

## Purpose

Publish a personal Games-sphere essay about why *Bloodborne* remains vital, using supplied artwork and captures as credited commentary material.

## Shape

- Slug: `bloodborne-still-hunts`
- Title: `Bloodborne Still Hunts`
- Type/layout: published `essay` with `feature` layout
- Sphere: `games`; tags cover Bloodborne, PlayStation 4, CRT play, game preservation, and emulation.
- Hero: supplied main-menu artwork. The gallery combines supplied action images, weapon sheets, and concept art.

## Editorial boundaries

- The prose is a personal assessment: it calls the game a timeless masterpiece and mentions playing it on a 480p CRT.
- The ShadPS4 link goes only to `https://shadps4.net/`. It describes the project as an early PS4 emulator, links to the official site, and tells readers to use software and game data they are legally entitled to use.
- It contains no downloads, keys, game files, BIOS instructions, piracy sources, or compatibility guarantees.
- Sony’s lack of a remake/remaster is framed as an absence around the game, not as a claim about rumours, leaks, or motives.

## Media and credits

All supplied media is copied to `public/media/games/bloodborne/` with concise lowercase names. Every entry receives a credit line identifying it as third-party promotional art, concept art, or game capture used for identification and critical commentary. The essay includes a note covering the complete set.

## Validation

Add a focused content test that verifies the article uses the Games sphere, its local hero and gallery assets exist, and its source link is the official ShadPS4 site. The existing publishing guard, Astro check, and static build must pass.

# Signals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a static archive of personally curated web links and model manga format separately from rating.

**Architecture:** A `signals` content collection supplies published external links to one static index route. Each Signal has a visibility state, URL, short note, tags, spheres, and an SFW/NSFW label; Manga keeps its single `rating` field and gains independent `format` and `origin` fields.

**Tech Stack:** Astro 7 Content Collections, Astro static routes, Markdown.

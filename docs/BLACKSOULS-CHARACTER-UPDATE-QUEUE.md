## Rules for every entry

1. Open the exact FGGuides source page and the exact local page in the in-app browser.
2. Compare the complete article structure, not only the title and first paragraph: route sections, H-scene sections, endings, captions, and source images all count.
3. Keep images beside the section they explain. Never append a second image dump at the end.
4. Treat `hero`, `media`, and Markdown body images as separate roles. Do not reuse the same image across those roles without a specific editorial reason.
5. Check image references against the external image root and verify that the image references are unique when the source uses distinct images.
6. Remove copied source-site chrome and footer navigation. Keep only useful local cross-links.
7. For recurring characters, add links to every applicable local page: BS1, BS2, and DEAD RED HOOD when relevant.
8. Run `bun run astro check` before moving to the next entry.
